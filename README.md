# Distributed File-Sharing System

A Java client-server application that allows users to register, search for, and share files between clients.

## Features
- Register and update shared files
- Search for available files
- Store client and file information in MySQL
- Transfer files directly between clients using Java sockets

## Technologies
- Java
- MySQL
- JDBC
- Java Sockets
